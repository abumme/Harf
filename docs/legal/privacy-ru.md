# Политика конфиденциальности приложения «Harf»

**Редакция от:** 2026-09-17


## 1. Общие положения

1.1. Настоящая Политика описывает, какие данные обрабатываются в мобильном приложении «Harf» (далее — «Приложение»), с какой целью и как они защищаются.

1.2. **Оператор данных:** Islomov Mekhrojbek, физическое лицо, Республика Узбекистан. Email: lazydevscat@gmail.com.

1.3. Обработка данных осуществляется в соответствии с Законом Республики Узбекистан «О персональных данных».

1.4. Устанавливая и используя Приложение, Пользователь соглашается с настоящей Политикой.

## 2. Какие данные обрабатываются

2.1. **Идентификатор аккаунта.** Приложение создаёт анонимный идентификатор аккаунта (случайный UUID). Он не содержит имени, телефона или иных прямых идентификаторов.

2.2. **Вход через Google или Apple (необязательно).** Если Пользователь входит через Google или Apple, на сервере сохраняются идентификатор провайдера (provider + subject id), позволяющий связать аккаунт при повторном входе, и отображаемое имя, которое Пользователь подтверждает при входе. **Адрес электронной почты и фото профиля на сервере не сохраняются.**

2.3. **Игровая статистика.** Для синхронизации прогресса между устройствами сохраняются: язык игры, номер ежедневного пазла, факт победы, число попыток и время обновления.

2.4. **Данные о покупках.** Внутриигровые покупки обрабатываются магазином Google Play и сервисом RevenueCat. Приложение получает только статус прав доступа (что куплено), но **не получает и не хранит платёжные реквизиты** (номера карт и т. п.).

2.5. **Локальные настройки.** Настройки и прогресс хранятся локально на устройстве Пользователя (тема, язык, незавершённая партия, локальная статистика).

2.6. Приложение **не собирает** геолокацию, контакты, микрофон, камеру и не показывает рекламу.

2.7. **Предложения слов (необязательно).** Если Пользователь предлагает добавить слово в словарь, на сервере сохраняются слово, его язык, время отправки и решение по нему (принято или отклонено). Предложение связано с аккаунтом до удаления аккаунта; после удаления предложение сохраняется без связи с аккаунтом.

## 3. Цели обработки

- Сохранение и синхронизация игрового прогресса между устройствами.
- Предоставление доступа к оплаченным дополнениям.
- Обеспечение работы входа в аккаунт и безопасности сессий.
- Анализ игровой статистики в обобщённом виде, без установления личности отдельных пользователей, чтобы понимать, как используется Приложение, и улучшать его.

## 4. Передача третьим лицам

4.1. Данные могут обрабатываться следующими сервисами в объёме, необходимом для работы Приложения:

- **Google Play** (Google LLC) — приём платежей и распространение Приложения.
- **RevenueCat, Inc.** — управление внутриигровыми покупками и правами доступа.
- **Google Sign-In / Apple Sign-In** — проверка входа (по выбору Пользователя).

4.2. Данные не продаются третьим лицам и не используются в рекламных целях.

## 5. Хранение и безопасность

5.1. Токены сессий хранятся на сервере только в виде хэшей. Передача данных между Приложением и сервером осуществляется по защищённому соединению (HTTPS).

5.2. Серверные данные хранятся до тех пор, пока существует аккаунт Пользователя. Обобщённая статистика, по которой нельзя установить личность, может храниться и после удаления аккаунта.

5.3. Уполномоченные администраторы Приложения могут получать доступ к данным аккаунта (идентификатор аккаунта, тип провайдера входа, отображаемое имя, игровая статистика и предложения слов) только для поддержки, модерации и предотвращения злоупотреблений; доступ есть только у учётных записей администраторов, а их действия записываются в журнал.

## 6. Права Пользователя

6.1. **Удаление аккаунта.** Пользователь может удалить свой аккаунт в Приложении; при удалении связанные серверные данные (идентификаторы входа, статистика, токены) удаляются каскадно. Удаление также может выполнить администратор по запросу Пользователя.

6.2. Пользователь вправе обратиться по адресу lazydevscat@gmail.com для получения информации об обработке своих данных.

## 7. Дети

7.1. Приложение не предназначено для сбора данных детей и не запрашивает данные, позволяющие определить возраст. Приложение не собирает персональные данные сверх описанного в разделе 2.
