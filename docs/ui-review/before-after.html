06

Dark editions — no white flash at night

Theming · Contrast

The app is white-only by construction: HarfTheme uses lightColorScheme, all five editions are light, and App.kt reports isDark=false unconditionally. Open the daily at 22:00 and it’s a full white flash. The same token pass fixes a real bug: in Fill/Outline mark styles the letter is the dark ink over a full navy correct fill — dark-on-dark. 07

What these share

System, not screens

→ One button system

Primary / ghost / danger as three tokenized styles reused everywhere — no per-screen hand-rolled Box+clickable chips, no equal-weight walls.

→ One top-bar

Labeled back + serif title, shared by Archive, Stats, Settings — fixes the desktop/web dead-end in one component.

→ Semantic tokens

Add danger / success roles so no screen reaches for a raw 0xFFD32F2F again — and they’ll carry into dark mode for free.

→ State & motion

Loading + empty states everywhere Paywall already has them, plus the one signature tile-flip reveal the game is missing.
