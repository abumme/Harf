#### Description (≤ 4000 chars)
```text
Harf is a daily word puzzle game. Every day, there is one new word for everyone. Guess it in six tries.

Each guess colors the tiles to guide you:
• Green: The letter is correct and in the right spot.
• Red / Yellow: The letter is in the word, but in a different position.
• Grey: The letter does not appear in the word at all.

FEATURES:
• One puzzle every day, identical for players worldwide
• Play in multiple languages: Uzbek (Latin & Cyrillic), Russian, Kazakh, and English
• Fully offline support: solve the daily word without an active internet connection
• Streak tracking and detailed player statistics
• Mindful, distraction-free aesthetic with multiple customizable themes
• Optional Sign in with Apple to seamlessly sync your streak across devices

Harf understands letters the way a native speaker does — for example, Uzbek "sh" and "oʻ" count as single letters, ensuring natural scoring and gameplay across every supported language.

One word a day. Come back tomorrow.
```

## 8. Сборка архива и отправка в TestFlight / App Store

### Способ 1: Через Xcode GUI
1. Открыть проект в Xcode:
   ```bash
   open iosApp/iosApp.xcodeproj
   ```
2. Выбрать схему **iosApp** и целевое устройство **Any iOS Device (arm64)**.
3. В меню Xcode выбрать **Product** → **Archive**.
4. После завершения архивации в окне Organizer нажать **Distribute App** → **App Store Connect** → **Upload**.

### Способ 2: Через командную строку (CLI)
```bash
# 1. Сборка архива .xcarchive
xcodebuild -project iosApp/iosApp.xcodeproj \
  -scheme iosApp \
  -configuration Release \
  -destination 'generic/platform=iOS' \
  -archivePath build/ios/Harf.xcarchive \
  archive

# 2. Экспорт .ipa и загрузка через altool / notarytool / Transporter
xcrun altool --upload-app -f build/ios/Harf.ipa -t ios -u "<apple-id>" -p "<app-specific-password>"
```
